# Projekt: dostępność i projektowanie przyjazne osobom w spektrum autyzmu

Pliki:
- `good.html` — wersja zgodna z dobrymi praktykami.
- `bad.html` — wersja celowo łamiąca zasady dostępności.
- `explanation.html` — krótkie omówienie.
- `index.html` — strona startowa z linkami.

## Publikacja na GitHub Pages
1. Utwórz nowe repozytorium na GitHubie.
2. Wgraj wszystkie pliki z tego folderu do głównego katalogu repozytorium.
3. Wejdź w Settings → Pages.
4. Wybierz źródło: Deploy from a branch.
5. Wybierz branch `main` i folder `/root`.
6. Po chwili GitHub pokaże adres strony.

Przykładowe linki po publikacji:
- `https://TWOJ_LOGIN.github.io/NAZWA_REPO/good.html`
- `https://TWOJ_LOGIN.github.io/NAZWA_REPO/bad.html`
